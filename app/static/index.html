软件更新

以代码仓库发布的 Release 为更新源：发布新版本后，点「检查更新」即可一键下载、替换并自动重启完成升级。访问令牌在托管平台的个人设置中创建，仅保存在本机数据库。守护模式（start-protected.bat）下请先关闭守护窗口再更新；安装在 Program Files 的目录可能因权限无法自动替换，需以管理员身份运行或改用安装包。
